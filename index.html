Deployment Instructions

To deploy this on a GitHub Repository for GitHub Pages:

  1. Create a public repository on GitHub.
  2. Upload index.html alongside these three script files to the root directory.
  3. Go to repository Settings > Pages.
  4. Set source to Deploy from a branch (main / root).
  5. Your portal will be live at https://<username>.github.io/<repo>/.
